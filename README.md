# Topos

Topos turns one room photo into a clean static AR canvas. Capture a room, mask clutter, erase it with AI, then place 3D furniture models.

## Stack

Next.js, React, TypeScript, Tailwind CSS, React Three Fiber, Three.js, Neon Postgres, WebAuthn passkeys, Replicate SDXL, and Cloudflare R2.

## Flow

Capture → mask → AI erase → furnish → save.
